# yokoi4rk

Standalone Yokoi Game & Watch emulator for RGDS+ Stock OS basing on https://github.com/PolluxPT/Yokoi-RGDSPlus

## Instruction

1. Extract `yokoi_pack_portmaster.ykp.7z.001/002` with 7zip and put `yokoi_pack_portmaster.ykp.7z` in to the `yokoi` folder.

2. Then copy `yokoi` folder and `Yokoi.sh` to ports folder on handheld.
